# DevOps Assignment 2

## 📌 Project Title

DevOps Assignment - Basic Git and GitHub Workflow

---

## 📖 Description

This project is created as part of my DevOps Assignment 2.
The main objective of this assignment is to understand and implement the basic concepts of **Git** and **GitHub**, including repository creation, file management, and version control.

---

## 🎯 Objectives

* To learn how to initialize a Git repository
* To understand version control using Git
* To create and manage files in a project
* To upload and manage code using GitHub
* To maintain project documentation using README

---

## 📂 Project Structure

The repository contains the following files:

* **index.html** → A simple HTML webpage
* **README.md** → Documentation of the project

---

## 💻 Technologies Used

* HTML
* Git
* GitHub

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the `index.html` file in any web browser
3. View the output

---

## 🔧 Steps Performed

1. Installed Git on the system
2. Created a new project folder
3. Initialized Git repository using `git init`
4. Created project files (`index.html`, `README.md`)
5. Added files using `git add`
6. Committed changes using `git commit`
7. Uploaded project to GitHub
